ZAHI FIT v2.4.0 — SMART PROGRESSION + EXERCISE-SPECIFIC TRACKING

This release is layered on top of the working v2.3.1 adaptive prescription.

Adds:
- Exercise-specific tracking UI
  - Strength/hypertrophy/power: kg + reps + RPE
  - Mobility/flexibility: reps/time only
  - Bike: resistance + interval target + RPE
  - StairMaster: level + interval/time target + RPE
  - Carries: kg + distance/time
- Exercise-specific PT progression guidance
- Previous-performance summary by exercise type
- Discard workout option that does not save to history
- Prevents finishing a workout when zero sets are completed
- Delete erroneous/test history entries
- Visible app version v2.4.0
- Cache synchronized to v2.4.0
