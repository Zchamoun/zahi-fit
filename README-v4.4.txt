ZAHI FIT v4.4.0 — INSTALL BUTTON

WHAT'S NEW
- "Install Zahi Fit" card on the Today screen and in Profile.
  - Android Chrome: tap Install → the phone's own install window opens → Install.
    The Zahi Fit icon is added to your home screen and opens full screen, offline-ready.
  - If the phone can't show the install window (iPhone, another browser, or Zahi Fit is already
    installed), the button reads "How to install" and shows the exact steps.
- "Not now" hides the card on Today; it stays available in Profile.
- Inside the installed app the card disappears and Profile shows "Installed ✓".
- Includes everything from v4.2 and v4.3.
