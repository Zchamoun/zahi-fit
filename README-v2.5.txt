ZAHI FIT v2.5.0 — FLEXIBLE PERSONAL TRAINING PLANNER

New in v2.5
- Choose 2, 3, 4, 5 or 6 training days per week.
- Choose a primary training goal:
  Fat loss, Muscle gain, Strength, Endurance, Athletic fitness, Mobility/flexibility.
- Add up to 3 secondary goals.
- Choose preferred session duration: 60, 75 or 90 minutes.
- Weekly program regenerates around frequency and primary goal.
- 2-day program uses two balanced full-body sessions.
- 3-day program uses posterior/lower, upper, and full-body athletic sessions.
- 4-day program preserves the proven A/B/C/D structure.
- 5- and 6-day plans add goal-specific booster sessions rather than simply repeating workouts.
- Home now shows weekly completed sessions against the selected weekly target.
- Live substitution flow asks why you need a replacement and proposes same-purpose built-in alternatives.
- Ask PT is available during the workout with quick questions and a custom question field.
- PT handoff includes goals, weekly frequency, readiness, current exercise, current sets, workout progress and recent history.

Important AI architecture note
- v2.5 uses a secure contextual handoff to the ChatGPT app.
- It does NOT place an OpenAI API key in browser code.
- Fully embedded AI responses inside Zahi Fit require a secure backend and should be implemented as a later release.
